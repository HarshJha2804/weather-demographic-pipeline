

\# Build an end to end automated data pipeline integrating live weather APIs with demographic data.



\## Project Overview

An automated data pipeline that collects weather

data from an API, combines it with demographic data,

loads the results into Google BigQuery, and visualizes

insights using Looker Studio.



\## Technologies

\- Python

\- Git and GitHub

\- Google Cloud BigQuery

\- SQL

\- Looker Studio



\## Project Structure

\- data/: Local datasets (excluded from Git)

\- src/: Python pipeline scripts

\- sql/: SQL transformations and analysis

\- tests/: Pipeline tests
